# supply-chain-analytics-project

## 📌 Project Overview
This project focuses on analyzing supply chain performance to identify inefficiencies, demand-supply gaps, and operational bottlenecks using data analytics.

## 🎯 Objectives
- Improve inventory visibility
- Analyze key supply chain KPIs
- Support data-driven decision making

## 📊 Key KPIs Analyzed
- Inventory Turnover
- Order Fulfillment Rate
- Lead Time
- Stock Availability
- Demand vs Supply Gap

## 🛠 Tools & Technologies
- Excel (Data Cleaning & Analysis)
- SQL (Data Querying – simulated)
- Power BI (Dashboard & Visualization)
- Tableau (Dashboard & Visualization)

## 📈 Key Insights
- Identified imbalance between regional demand and inventory levels
- Highlighted delays caused by supplier lead times
- Recommended data-backed inventory optimization strategies

## 🧠 Business Impact
The analysis helps improve service levels, reduce stock-outs, and enhance supply chain efficiency.
